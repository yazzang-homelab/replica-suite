# Report contract
1. Target request (method, URL pattern) and parameter location.
2. Script URL and function(s) participating; call chain order.
3. Evidence per claim: request id, stack, breakpoint/hook output, runtime values (redacted).
4. Reproduction status: stable / flaky / not yet; test command and sample count.
5. Environment dependencies list (time, random, storage, cookie, UA, canvas, crypto).
6. If unfinished: the one remaining environment gap and next probe.
