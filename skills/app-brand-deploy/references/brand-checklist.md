# Brand checklist

## Name checks (record date + result per candidate)
| check | where |
| --- | --- |
| domains | registrar search / whois (.com .app .io .co) |
| App Store, Google Play | search exact name |
| handles | X, Instagram, TikTok, LinkedIn, GitHub |
| US trademark | tmsearch.uspto.gov, classes 9 and 42 |
| EU / many offices | EUIPO eSearch, TMview |
| global | WIPO Global Brand Database |
| web | "<name> <category>" search |
Screening only, not legal clearance; a trademark lawyer does a proper search before money is spent.

## Logo brief (not a logo)
One-line idea tied to name and opening; wordmark | symbol+wordmark | monogram; legible at 16px favicon and as 1024px app icon (no transparency for iOS); deliverables SVG, app icon, favicon set, 1200x630 share image; put the original's mark beside drafts: no shared shape, colour pair or letterform trick.

## Voice
Three words each with "not" (direct, not blunt); five do/don't pairs; rewrite sign-up, main button, empty states, confirmation, main error. Fresh wording, nothing echoing the original.

## Store listing limits (verify current values in the consoles)
App Store: name 30, subtitle 30, promo text 170, keywords 100, description 4000. Google Play: title 30, short description 80, full 4000. Flag: original's name anywhere, ranking claims ("#1"), price claims in short fields, emoji in name, wasted keyword characters (repeating title words, spaces after commas). Prepare screenshots at required sizes, privacy labels / data safety form, privacy policy + support URL, age rating, review notes with demo account.

## Pricing table
Original plans + 2-3 alternatives, each with URL and date read; model (free/trial, flat vs per seat, monthly/yearly); at most three plans named for who they serve.
